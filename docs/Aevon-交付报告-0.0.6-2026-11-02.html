01

为什么那八行点不动

Root.plist · 0.0.5

0.0.5 用的是 PSChildPaneSpecifier，期望框架自己 push 下一级。实际结果是： 这一版 iOS 不为这个 cell 类提供选中态，点击不产生任何事件，界面渲染成普通文字行 —— 没有箭头、没有高亮、没有跳转。 plist 是对的，面板文件也在包里，但手指这一侧是断的。

0.0.5 依赖框架

  • cell = PSChildPaneSpecifier
  • push 由 Preferences.framework 决定
  • cell 类不认识 → 静默降级成文字行
  • 失败时没有任何日志，只能看到「点不动」

0.0.6 自己接管

  • cell = PSButtonCell + action = openPanel:
  • 按钮可点由框架保证，与 iOS 版本无关
  • push 由 RootListController 自己做
  • 每次打开都写一行 prefs: open panel <id>

代价是这八行不再有向右的箭头，显示为蓝色可点文字 —— 用一点点视觉习惯，换「一定点得开」。 如果某一行点了没反应，日志里没有 open panel，就能立刻区分是按钮没接上，还是页面没加载。

02

面板：从「只读」到「可写」

PanelController.swift

新的 PanelController 是通用子页面：给它一个面板名，它用和根页面同一套三层装载 去读对应的 plist，读不到就渲染一行可读的诊断，而不是空白页。 

// 三层装载：与 0.0.4 修好根页面的逻辑完全一致
1 loadSpecifiersFromPlistName:target:            // 老 API，一定存在
2 loadSpecifiersFromPlistName:target:bundle:     // 新重载，responds(to:) 保护
3 nil  → 调用方画一行诊断（bundle 路径 + plist 状态）

// 写入：开关/滑杆全部走 super，落进 com.aevon 域
override setPreferenceValue(_ value: Any?, specifier: PSSpecifier)

// 四形状互斥：写 true 的同时把其余三个写成 false
RTSIF / RTSIH / RTSIQ / RTSIZ   → 同一笔写入里完成

「当前承载」这一行不是静态文案：它每次从 RingConfig.load() 现算， 拖动半径或切形状后只刷新这一行，不整表重载 —— 否则手指还按在滑杆上，table 就被重建了。

接通链路：一次拖动，四处落地

ring.plist + Darwin

设置进程和 SpringBoard 是两个进程，roothide 下 Library/Preferences 还会按进程重定向， 同一个域可能读到两份。所以运行参数走一条普通路径的文件，偏好域只作为界面侧的存储。

  拖动半径 ──▶ com.aevon 域  // 界面持久化

                 ▼  notify_post("com.aevon.prefs")

两个通知名各配一个回调：com.aevon.command 管重载/重置， com.aevon.prefs 管参数。这样回调不需要知道「这次是哪个通知」—— CFNotificationName 到 Swift String 的桥接在这套工具链上不成立，与其绕，不如让注册处直接说明身份。

04

桌面宿主：只占两个点，不占一次触摸

RingHost.swift

宿主是一个独立 UIWindow（level = normal + 1），根视图与窗口都重写了 hitTest：除了 40pt 的握把热区与图标本身，其余点一律返回 nil，落回桌面。 收起时桌面上只有一个 14pt 的半透明白点，没有任何常驻遮罩，也没有劫持手势。

行为实现为什么这样
展开点握把 → ring.appear()图标从握把位置绽放，与 GIF 里的运动一致
收起disappear() 后移除视图不留隐藏视图，不留后台动画
点图标LSApplicationWorkspace 启动，随后收起SpringBoard 自己用的入口，逐级 responds 保护
触摸窗口 / 根视图 / RingView 三层 hitTest空处必须穿透，否则全屏视图会吞掉桌面每一次点击
旋转方向变化 → 重算枢轴到右下角握把始终在手指容易够到的位置
关闭面板开关 → 直接销毁窗口不需要重载桌面，也不需要重启

安全边界

  • G0/G1 任一开启时根本不挂载
  • 构造函数内不建窗口，延迟 2 秒到主场景就绪
  • 不用 UIApplication.shared 强解包，走 runtime 取，取不到就退回无场景窗口
  • 图标源全部失败也只是占位色块，不影响形状

仍然没做

  • 边缘手势呼出（P3）—— 风险最高，放最后
  • 收藏置顶、旋转自适应/立即/延迟
  • 拖拽握把改枢轴位置
  • 浮窗 Scene：现在环属于桌面，不属于某个 App

真机验收：先看这四条

不需要终端
1

安装后重载桌面一次仅此一次

设置 → Aevon → 重载桌面。之后所有参数改动都不再需要重载。

桌面右下角出现一个 14pt 半透明白点，其余区域触摸手感与未安装一致。
2

八行都能点开

功能设置下的八行都是蓝色可点文字，逐行进入都有内容，返回正常。

每进入一次，日志多一行 prefs: open panel <id>。
若显示「面板未能加载」，是 plist 没进包 —— 把这行与日志一起回传。
3

改半径，直接看桌面

承载形状 → 半径 64 → 110，收起面板回桌面，点白点展开。

环明显变大，数量随之变化；「当前承载」与「桌面状态」同步更新。
桌面没变化 → 看日志有没有 ring: live update；没有就是通知没到。
4

关掉开关，白点应当消失

关「桌面显示握把」→ 立即销毁窗口；再打开 → 立即回来。

全程不重载桌面、不重启 SpringBoard。
