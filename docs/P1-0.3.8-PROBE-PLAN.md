# Aevon 0.3.8 取证方案 — 照母版 P1 的承载链，只问不做

> 依据：`Stheno-1比1复刻方案-2026-11-02.md` §P1（第 108 行起）
> 原则：**先取证，不 hook**。任一符号不符 → fail-closed，不动手。

## 一、母版 P1 的六步（原文）

```
1. 探测：NSClassFromString + respondsToSelector + method_getTypeEncoding，任一不符 → fail-closed
2. 取 App 已有的主场景 handle（不要新建场景 —— 母本也不新建）
3. 建 presenter，把 SBDeviceApplicationSceneViewController 的 view 挂进 _UIContextLayerHostView
4. 建 SthenoWindow(windowScene:) 作为浮窗根，层级放在状态栏之下、App 之上
5. 内容用 MIN 等比铺满：inverseScale = MIN(w/sw, h/sh)，不裁切
6. 关窗：先撤 presenter → 再释放持有 → 最后才允许场景回收
```

## 三、0.3.8 要问的问题（只读，一次装机能答完）

### 线 D：`SthenoWindow` 那条路在本机成不成立

| # | 问什么 | 判据 |
|---|---|---|
| 1 | `UIWindow` 有没有 `initWithWindowScene:` | 有 ⇒ 我们可以照建 |
| 2 | 本机 `SBDeviceApplicationSceneViewController` 在不在、有没有 `newSceneViewController` / `view` | 在 ⇒ 能借场景视图 |
| 3 | `_UIContextLayerHostView` 有没有 `initWithSceneLayer:` | 有 ⇒ 能建宿主 |
| 4 | `UIScenePresentationManager` 的 `createPresenterWithIdentifier:priority:` 编码 | 已知 `@32@0:8@16q24`，复核 |
| 5 | `UIMutableScenePresentationContext` 的 `setResizesHostedContext:` | 已证 `v20@0:8B16`，复核 |

### 线 E：`_dismissPresentable` / `deactivateWithTransitionContext` 的归属与编码

这两条母版各用 2 次，Aevon **0 次调用**。它们很可能就是「把系统那扇全屏窗收掉」的入口。

| # | 问什么 |

| 7 | `deactivateWithTransitionContext:` 的归属类与编码 |
| 8 | 本机有没有 `SBTransientOverlayPresenter` / `SBTransientOverlayViewController` |

## 五、这一版**不做**的事

1. **不重建承载层** —— 那是 0.3.9 的事，前提是这一版的读数全部达标。
2. **不改任何行为** —— URL 已清零（纯放行），承载层维持现状。
3. **不动 `FloatHost`** —— 现有卡片仍按老路走（借系统 scene 的 presenter）。
4. **不碰圆盘 / 手势 / 键盘**。
