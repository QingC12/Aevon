# 阶段计划与验收闸门

每一期都产出一个可独立安装、可独立回退的 deb。**上一期真机验收不通过，不允许开下一期。**

| 期 | 内容 | 关键产出 | 验收闸门（全部真机通过才算过） |
|---|---|---|---|
| **P0** | 安全骨架 | 空 hook dylib + 三道闸门 + CI + 设置入口 | 见下方 0.0.3 清单 |
| **P1** | 承载模型 | `UIScenePresentationManager` 建立独立 Scene | 空窗口常驻 30 分钟不崩、不卡、不发热异常 |
| **P2** | 几何 | 窗口尺寸/圆角/贴边/比例 | 旋转、分屏、键盘弹出后几何不漂 |
| **P3** | 手势 | 拖动、甩动、贴边缩入、长按 | 连续 200 次操作无丢手势、无卡死 |
| **P4** | 圆盘 | 扇形展开、图标排布、旋转 | 展开/收起 100 次无可感知掉帧 |
| **P5** | 保活 | `interceptUpdateWithNewSettings:` 改参数 | 后台 8 小时窗口仍在，且**不产生额外 Assertion 日志** |
| **P6** | 键盘 | 独立键盘桥 dylib | 键盘弹出/收起时窗口避让正确，输入不丢焦点 |
| **P7** | 设置 | 64 个开关逐个接通（81 键对齐） | 每个开关改完重载桌面后行为正确 |
| **P8** | 扩展 | URL/通知/外跳拦截 | 只对用户显式添加的 App 生效，不误伤系统 |
| **P9** | 验收 | 双机盲测 | 与母本同一档位可调，盲测说不出差别 |

## 0.0.3 验收清单（当前阶段，全部在界面里完成，不需要终端）

装完 deb 后 **不要**先重载桌面：

- [ ] 打开「设置」，**第一屏就能看到 Aevon 一行**（`postinst` 已经替你重启过 Preferences；如果还是没有，先把设置彻底划掉再打开一次）
- [ ] 点进去，能看到「状态 / 安全闸门 / 功能设置 / 关于」四组，以及 8 个功能面板
- [ ] 「注入状态」显示 **运行中** 或 **未加载**（此时还没重载桌面，`未加载` 是正常的）
- [ ] 「日志文件」显示 `/var/mobile/Aevon.log`
- [ ] 点「重载桌面（应用闸门变更）」→ 桌面重启 → 再进设置，状态变成 **运行中**，「启动次数」≥ 1
- [ ] 60 秒后再看，「启动次数」回到 0（心跳清计数）
- [ ] 打开「紧急停止（G0）」→ 重载桌面 → 状态变成 **已紧急停止（G0）**，桌面行为与未安装时完全一致
- [ ] 关闭 G0 → 重载桌面 → 状态回到 **运行中**
- [ ] 打开「暂停注入（G1）」→ 重载桌面 → 状态 **已暂停注入（G1）**；关掉后同样能恢复
- [ ] 连续 4 次「重载后 30 秒内再重载」不会误触发 G2（G2 只在 5 分钟内超过 3 次才动手）
- [ ] 用 Filza 建 `/var/mobile/Library/Logs/Aevon/panic` → 重载桌面 → 状态 **已紧急停止（G0）**；删掉文件 → 重载 → 恢复

**任何一项不过，不进入 P1。**

## P1 的前置取证（必须在写代码之前完成）

0.0.3 起**探针已从包里移除**（体积预算 + 只在需要时才编进去）。P1 开工时用一次性构建的取证版：

1. **`_scene:interceptUpdateWithNewSettings:` 的返回值语义**
   用 `method_getTypeEncoding` 读出签名，确认返回类型与参数含义；在单个 Scene 上看 20 次真实调用。
   猜错 = SpringBoard 崩。
2. **浮窗 Scene 与 App 主场景的父子关系**
   场景树 dump，确认 `UIScenePresentationManager` 创建的 presenter 挂在哪个 `FBScene` 下。

两项的结果都写进 `/var/mobile/Aevon.log`，从设置里直接看，不需要终端。

第三项（圆盘展开插值曲线）可以纯本地做：二进制在手，capstone 已具备，只差定位函数入口。

## 回退策略

- 本项目**不建 Release、不打 tag**：旧包只存在本机 `dist/`，回退 = 重新安装旧 deb；
- 状态文件跨版本保留，所以"降级后仍被自禁用"是预期行为，需要点「清除崩溃计数」显式重置；
- 版本号写在三处（`control`、`Sources/Core/Paths.swift`、面板 `Info.plist`），CI 的 preflight 会断言三者一致。
