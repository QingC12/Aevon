# 阶段计划与验收闸门

每一期都产出一个可独立安装、可独立回退的 deb。**上一期真机验收不通过，不允许开下一期。**

| 期 | 内容 | 关键产出 | 验收闸门（全部真机通过才算过） |
|---|---|---|---|
| **P0** | 安全骨架 | 空 hook dylib + 三道闸门 + CI + 设置入口 | 见下方 0.0.3 清单 |
| **P1** | 承载模型 | `UIScenePresentationManager` 建立独立 Scene | 空窗口常驻 30 分钟不崩、不卡、不发热异常 |
| **P2** | 几何 | 窗口尺寸/圆角/贴边/比例 | 旋转、分屏、键盘弹出后几何不漂 |
| **P3** | 手势 | 拖动、甩动、贴边缩入、长按 | 连续 200 次操作无丢手势、无卡死 |
| **P4** | 圆盘 | 扇形展开、图标排布、旋转 | 展开/收起 100 次无可感知掉帧 —— **0.0.5 已先交付「形状本身」**（几何/动画/四形状，宿主在设置内预览），宿主与展开收起仍排在 P1 之后 |
| **P5** | 保活 | `interceptUpdateWithNewSettings:` 改参数 | 后台 8 小时窗口仍在，且**不产生额外 Assertion 日志** |
| **P6** | 键盘 | 独立键盘桥 dylib | 键盘弹出/收起时窗口避让正确，输入不丢焦点 |
| **P7** | 设置 | 64 个开关逐个接通（81 键对齐） | 每个开关改完重载桌面后行为正确 |
| **P8** | 扩展 | URL/通知/外跳拦截 | 只对用户显式添加的 App 生效，不误伤系统 |
| **P9** | 验收 | 双机盲测 | 与母本同一档位可调，盲测说不出差别 |

## 0.0.3 验收清单（当前阶段，全部在界面里完成，不需要终端）

装完 deb 后 **不要**先重载桌面：

- [ ] 打开「设置」，**第一屏就能看到 Aevon 一行**（`postinst` 已经替你重启过 Preferences；如果还是没有，先把设置彻底划掉再打开一次）
- [ ] 点进去，能看到「状态 / 安全闸门 / 功能设置 / 关于」四组，以及 8 个功能面板
- [ ] 「注入状态」显示 **运行中** 或 **未加载**（此时还没重载桌面，`未加载` 是正常的）
- [ ] 「日志文件」显示 `/var/mobile/Aevon.log`
- [ ] 点「重载桌面（应用闸门变更）」→ 桌面重启 → 再进设置，状态变成 **运行中**，「启动次数」≥ 1
- [ ] 60 秒后再看，「启动次数」回到 0（心跳清计数）
- [ ] 打开「紧急停止（G0）」→ 重载桌面 → 状态变成 **已紧急停止（G0）**，桌面行为与未安装时完全一致
- [ ] 关闭 G0 → 重载桌面 → 状态回到 **运行中**
- [ ] 打开「暂停注入（G1）」→ 重载桌面 → 状态 **已暂停注入（G1）**；关掉后同样能恢复
- [ ] 连续 4 次「重载后 30 秒内再重载」不会误触发 G2（G2 只在 5 分钟内超过 3 次才动手）
- [ ] 用 Filza 建 `/var/mobile/Library/Logs/Aevon/panic` → 重载桌面 → 状态 **已紧急停止（G0）**；删掉文件 → 重载 → 恢复

**任何一项不过，不进入 P1。**

## 0.0.5 验收清单（承载形状，不需要终端、不需要重启）

- [ ] 设置 → Aevon → 功能设置 → **承载形状**，面板最上面出现「预览」组三行
- [ ] 「当前承载」显示 `圆盘 · R64 · 44pt · 7 个 · 起点 0°` 一类文字（不是 `—`）
- [ ] 点「预览承载形状（全屏）」→ 直接全屏，**图标从中心扩散出来**并逐个放大落位
- [ ] 预览页顶部第三行写明图标来源（LaunchServices / 文件扫描 / 占位图标）
- [ ] 点任意图标 → 轻震 + 图标弹一下 + 浮出 App 名称
- [ ] 关掉后改「半圆盘」→ 再预览只剩上半圆 4 个；改「直角盘」→ 只剩 2 个
- [ ] 打开其中任一个形状时，其余三个**自动关闭**（截图给不出四个同时为蓝）
- [ ] 半径拉到 120、图标宽度拉到 28 → 再预览，图标变小变远且**数量变多**
- [ ] 打开「任意角度」→ 在预览里按住拖动，整盘跟手旋转
- [ ] `/var/mobile/Aevon.log` 里出现 `ring preview shape=… icons=… source=… in Nms`

**第 1、2、3 项任一不过，先不进入浮窗宿主阶段** —— 形状是本项目唯一「可以纯本地验证」的部分，先在设置里调到自己满意，接上窗口后就不用再反复重启试参数。

## 0.0.6 验收清单（面板可进入 + 桌面接通，仍然不需要终端）

这一期只做两件事：把 0.0.5 那 8 行点不动的面板变成真能进、真能改的页面；把 RingView 挂到桌面，让设置里的参数有看得见的结果。

**A. 面板全部可进入**

- [ ] 设置 → Aevon → 功能设置：八行（窗口与场景 / 承载形状 / 手势与动效 / 键盘与输入 / 通知 / 跳转与伪装 / 监听与系统动作 / 应用与全局）都是**蓝色可点文字**
- [ ] 逐行点进去，每一页都有内容，标题是面板名，返回后仍在 Aevon 主页面
- [ ] 任意一页的开关能拨动，退出再进入**保持拨动后的状态**
- [ ] 任意一页的滑杆能拖动，数值跟着变，退出再进入**保持拖到的位置**
- [ ] 若某页显示「面板未能加载」，把页面上那三行连同 `/var/mobile/Aevon.log` 回传（这条路径说明 plist 没打进包，属打包错误）

**B. 承载形状与桌面接通（本期重点）**

- [ ] 装完重载桌面一次；回到桌面，**右下角出现一个 14pt 半透明白点**，其余地方触摸手感与未安装时完全一样
- [ ] 点白点 → 图标从白点位置**逐个绽放**成当前形状；再点白点 → 收回白点
- [ ] 打开「承载形状」：**「当前承载」有值**，**「桌面状态」显示「开关已开启 · 圆盘 · R64 …」**
- [ ] 把半径从 64 拖到 110 → **不做任何操作直接看桌面**（收起状态），再点白点展开，环明显变大
- [ ] 切「半圆盘」→ 桌面展开只剩 4 个；切「直角盘」→ 只剩 2 个（与预览页数量一致）
- [ ] 切「任意角度」→ 桌面展开后按住图标拖动，整盘跟手转；松手后角度保持
- [ ] 拖「速度」到 2.0 → 展开明显变快；拖到 0.2 → 明显变慢
- [ ] 点环上任意图标 → App 启动，环自动收回
- [ ] 关掉「桌面显示握把」→ **白点立即消失，不需要重载桌面**；再打开 → 立即回来
- [ ] 开着 G0 或 G1 重载桌面 → 桌面**没有白点**，状态为「未加载 / 已停止」
- [ ] `/var/mobile/Aevon.log` 出现 `ring: hosted on desktop`、`ring: live update -> …`、`ring: launch <bundleID>`

**C. 不通过时的定位顺序**

1. 面板点不动 → 看日志有没有 `prefs: open panel <id>`；没有就是按钮的 action 没接上
2. 桌面没有白点 → 先确认「桌面显示握把」为开，再看日志有没有 `ring: hosted`
3. 有白点但点开是空环 → 看 `ring: N apps via <source>`，N=0 说明图标源全部失败（不影响形状判断）
4. 改参数桌面不变 → 看日志有没有 `prefs: <key>=… ->` 与随后的 `ring: live update`

## P1 的前置取证（必须在写代码之前完成）

0.0.3 起**探针已从包里移除**（体积预算 + 只在需要时才编进去）。P1 开工时用一次性构建的取证版：

1. **`_scene:interceptUpdateWithNewSettings:` 的返回值语义**
   用 `method_getTypeEncoding` 读出签名，确认返回类型与参数含义；在单个 Scene 上看 20 次真实调用。
   猜错 = SpringBoard 崩。
2. **浮窗 Scene 与 App 主场景的父子关系**
   场景树 dump，确认 `UIScenePresentationManager` 创建的 presenter 挂在哪个 `FBScene` 下。

两项的结果都写进 `/var/mobile/Aevon.log`，从设置里直接看，不需要终端。

第三项（圆盘展开插值曲线）可以纯本地做：二进制在手，capstone 已具备，只差定位函数入口。

## 回退策略

- 本项目**不建 Release、不打 tag**：旧包只存在本机 `dist/`，回退 = 重新安装旧 deb；
- 状态文件跨版本保留，所以"降级后仍被自禁用"是预期行为，需要点「清除崩溃计数」显式重置；
- 版本号写在三处（`control`、`Sources/Core/Paths.swift`、面板 `Info.plist`），CI 的 preflight 会断言三者一致。
